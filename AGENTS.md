# Project writing instructions

This repository publishes the personal Korean nonfiction site mino.co.kr.

**Before every writing/editing/publishing request, read `EDITORIAL_GUIDE.md` in full.**
Read it again after the first complete draft and before publishing. Do not rely only on remembered instructions, previous chat summaries, or a brief excerpt.

- Inspect the actual source Markdown, rendered standalone HTML, and relevant earlier essays before altering an existing piece.
- Preserve the author's cautious, measured voice, narrative detail, scientific humility, anonymity preferences, and deliberately unresolved questions.
- Preserve public URLs, article order, metadata, share/reaction controls, discussion disclosure, and existing reaction data.
- Update both Markdown and the public HTML edition whenever both exist.
- Publishing changes requires the author's explicit instruction. Verify CI tests and deployment status before reporting publication complete.
- Never present made-up dialogue as a verbatim record. Treat reconstructed dialogues as paraphrases.
- See `EDITORIAL_GUIDE.md` for the full editorial and release checklist.
