# 『일과 삶 사이에서』 단행본 통합 퇴고 기록

이 편집본은 별도 원고 **books/vol1/manuscript.md** 에만 적용되며 기존 사이트의 열 편의 웹 에세이는 수정하지 않았다. 개인 정보가 포함되는 부분은 외부 출판 전 저자가 다시 확인할 것.

## 편집 방향

- 개별 에세이를 집필·발행한 순서 대신 질문의 인과적 흐름으로 3부 10장 재구성.
- 가장 중요한 중복 축 3개: **생산성·인간 가치**, **결과보다 과정/도전**, **AI가 생산한 풍요와 분배**. 각 축의 본 논의가 나타나는 장을 유지하고 다른 장의 반복은 통합.
- 다른 글에서 같은 예시를 두 번 설명하는 부분은 통합해, 앞선 장을 읽었다는 전제에서 자연스럽게 연결되도록 연결 문단을 추가.
- AI가 이미 인간의 모든 능력을 넘어섰다는 단정 없이, 현재 기술과 미래 사고실험을 구분.
- 웹 에세이는 독립된 완결성을 유지해야 하므로 편집은 책 전용 원고에서만 진행.

## 실제 반영한 중복 통합

1. **아이들은 무엇을 위해 공부하는가** — 「놀이에도 성적표를 붙이는 사람들」 부분을 책에서 통합 (약 1542자). 아홉 번째 글의 성적표·인정 욕구 논의가 해당 주제를 더 개인적인 장면에서 완성하므로 책에서는 중복 절을 통합.
2. **물고기를 사지 않고 낚으러 가는 이유** — 「쓸모 있는 사람이 되고 싶다는 마음」 부분을 책에서 통합 (약 1439자). 첫 글의 노동의 의미, 아홉 번째 글의 성과·존재 가치 논의와 중복; 낚시라는 고유한 현장으로 바로 전개.
3. **인간은 더 이상 일하지 않아도 되는가** — 「잘하는 것과 하고 싶은 것은 다르다」 부분을 책에서 통합 (약 957자). 낚시 글의 결과/과정 논점과 아홉 번째 글의 우열/의미 논점이 중복; 경제·분배의 고유 논의에 집중.
4. **우리는 이해하지 못하는 것을 만들기 시작했다** — 「스스로 할 수 있다는 것」 부분을 책에서 통합 (약 685자). 뒤의 신뢰 글에서 직접 만들고 검증하는 문제를 더 구체적으로 다루므로 편집본에서는 관련 문제를 뒤에 배치.
5. **똑똑한 기계 앞에서 망설이는 사람** — 「그래도 만들고 싶은 것」 부분을 책에서 통합 (약 1308자). 아홉 번째 글에서 만들고 싶은 이유를 생활적 사례로 충분히 전개하여 중복을 줄임.
6. **내 인생은 내가 살아볼게** — 「세상에서 제일 잘하지 않아도」 부분을 책에서 통합 (약 1135자). 낚시 글의 비경쟁적 활동과 크게 겹쳐 이 글은 인정·행복의 선택권 문제에서 시작하도록 편집.
7. **그래도 우리는 내일을 살아간다** — 「일하지 않아도 되는 세상은 누구의 것인가」 부분을 책에서 통합 (약 1165자). 네 번째 글의 분배·소득 논의를 되풀이하므로 책의 마지막은 경영자이자 부모의 두 입장에 집중.

## 장별 고유 역할

### 제1부 · 일을 넘어
- **우리는 무엇을 위해 일해왔는가**: 문자·인쇄·AI의 기술사를 통해 노동의 의미를 여는 첫 질문
- **아이들은 무엇을 위해 공부하는가**: 아이들의 현재 삶에서 교육과 노력의 비용을 살피는 장
- **물고기를 사지 않고 낚으러 가는 이유**: 자발적 놀이와 비효율적 활동의 자체 가치를 구체화하는 장
- **인간은 더 이상 일하지 않아도 되는가**: 기술적 생산과 경제적 분배·노동의 자유를 구별하는 장

### 제2부 · 우리가 만든 것의 바깥
- **우리는 이해하지 못하는 것을 만들기 시작했다**: 한 사람의 무지와 공동체의 이해 불가능성을 나누는 장
- **똑똑한 기계 앞에서 망설이는 사람**: 검증·전문성·신뢰가 형성되는 과정을 살피는 장
- **우리가 만든 세상에 순응하는 날**: AI 문명의 통제·순응을 사회제도와 자연법칙의 비교로 묻는 장

### 제3부 · 살아갈 시간
- **인간은 왜 다른 인간을 필요로 하는가**: 인간관계를 AI 서비스와 구별하는 관계의 질문
- **내 인생은 내가 살아볼게**: 개인의 경험·성취·인정·선택권을 다루는 장
- **그래도 우리는 내일을 살아간다**: 경영자와 부모의 구체적 입장에서 다음 세대의 경제적 조건을 묻는 결말

## 그림 설명

- **01-paths.svg**: 같은 길이 갈라지고 다시 만나는 세 개의 흐름. 제1부 시작에 삽입.
- **02-control.svg**: 복잡한 판단의 망과 그 안에 있는 작은 중심. 제2부 시작에 삽입.
- **03-piano.svg**: 창가의 건반에 비치는 빛. 제3부 시작에 삽입.

SVG는 벡터 원본으로, 인쇄할 때 판형에 맞춰 손실 없이 배치할 수 있다. 생성형 이미지 시안과 실제 원고에 포함된 SVG는 별도 자산이며, 책에 들어간 것은 SVG 3개다.

## 2차 교정 시 점검할 사항

- 영국의 동물보호법·기본소득·고대 문자와 종이 역사 등 외부 사실은 편집본 출판 전 원전·각주를 다시 대조.
- 가족 관련 실제 장면과 이름의 의미를 출판본에 공개할지 저자 최종 확인.
- 단행본 조판 단계에서 웹 글 특유의 긴 소제목을 줄이고 실제 지면 길이로 다시 교정.
- 공통 해법을 억지로 부여하지 말고, 각 장의 불일치와 미완성 질문을 그대로 살릴 것.
