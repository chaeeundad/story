# 아직 생각 중입니다 - 원본 삽화 패키지

총 16점. 01~08은 고해상도 장면 삽화, 09~16은 콜라주에서 분리한 작은 본문용 비네트입니다.

모든 그림은 따뜻한 크림/세이지/황토색과 아날로그 인쇄 질감을 공유합니다. 인쇄용에서는 색상 모드와 300dpi 실효 해상도를 확인하세요.

## 편집 주의

실제 인물이나 특정 가족의 외모를 재현한 그림이 아닌 창작 장면입니다. 08번 피아노 연주도 실제 사건의 기록이 아닌 상상 장면으로 표기하면 안전합니다.
콜라주 추출본 09~16은 384x256px 수준이므로 B5 지면에서 작은 삽화로만 사용하고 확대 인쇄는 피하세요.
01~08 또한 실제 픽셀 크기에 따라 인쇄 시 배치 폭을 조절하세요.
이미지 생성 원본은 PNG 형식이며 서식에 맞춰 사용하기 전 최종 인쇄 색상 확인을 권장합니다.
