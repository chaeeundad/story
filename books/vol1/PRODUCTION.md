# 『아직 생각 중입니다』 제작 기록

부제: **AI 시대를 맞이하는 IT 회사 대표이자 세 딸 아빠의 생각**. 저자: mino.

## 원고와 웹판

- 원고는 `manuscript.md` 111,055자(공백·Markdown 포함), 3부 10장이다. 기존 통합 퇴고본의 본문을 유지하고 제목·부제·머리말 표기·차례 번호와 소제목 앞 빈 줄을 정리했다.
- `/books/vol1/`에서 전체 원고를 직접 불러온다. 13개 부·장 이동 링크, 읽기 진행 표시, 주소 복사, 삽화 3점을 제공한다.
- 홈페이지에 책 읽기 링크와 sitemap 항목을 추가했다. 기존 열 편의 원고·독립 HTML·URL·순서·공감 데이터 및 API 코드는 변경하지 않았다.
- Markdown의 물결표가 수치 범위를 취소선으로 바꾸지 않도록 GFM을 끄고 원래 문장부호를 유지한다. SVG는 원본을 제공한다.

## 인쇄용 DOCX

저자가 이전 대화에 첨부한 `[워드서식]B5(46배판)_부크크서식(기본).docx` 원본을 사용했다. 이전 환경의 `/mnt/data/` 경로 대신 현재 환경의 첨부파일 미리보기 보관 위치에서 동일 원본을 확보했다.

- 원본 판면 10,660×14,912 twips(약 188×263mm, 3mm 재단 여백 포함)를 보존했다. 재단 후 182×257mm에 해당한다.
- 본문 서식의 여백·제본 여백·11pt 부크크 명조 Light·20pt 줄간격·첫줄 들여쓰기·장평을 재사용했다. 원본의 안내 및 어린 왕자 예제와 예제 ISBN을 제거했다.
- 속표지, 이동 가능한 차례, 머리말, 부별 삽화, 10개 장, 판권을 포함한다. 미확정 ISBN·출판사·가격·인쇄일은 만들지 않았다.
- SVG 3점을 폭 3,200px PNG로 변환하여 120mm 폭에 배치했다(약 677dpi). 웹과 저장소에는 SVG 원본을 보존한다.
- 부크크 명조 Light 원본 폰트를 인쇄·미리보기용으로 내장했다. 글꼴 출처를 판권에 표시했다.
- 최종 렌더는 125쪽이며 실제 시작 쪽은 `print-page-map.json`에 기록했다. 차례의 쪽수는 해당 렌더에 맞춰 확정했다. 이후 원고·서식을 수정하면 다시 조판하여 차례 쪽수를 갱신해야 한다.
- 전달 DOCX의 크기와 SHA-256은 `print-artifact.json`에 기록했다. DOCX 및 임시 렌더는 Git 저장소에 포함하지 않는다.

## 제작 재현

`scripts/build-book-docx.py`는 Python의 `python-docx`, `lxml`을 사용한다. 별도 자산 디렉터리에 `BookkMyungjo-Light.ttf`와 SVG 파일명에 대응하는 PNG 3개가 필요하다. 원본 서식 파일은 저자 첨부파일을 사용한다.

```sh
python scripts/build-book-docx.py TEMPLATE.docx ASSETS_DIR OUTPUT.docx books/vol1/print-page-map.json
```

빌더는 원본 패키지에서 수정 대상 XML·메타데이터·머리말/꼬리말·이미지·폰트만 교체하고 테마·번호 정의 등 나머지 패키지 부분을 보존한다. 자산 디렉터리의 `template-inventory.json`에 원본 체크섬과 부분별 보존 여부를 남긴다.

## 검증 기록

- 원고 본문 625개 블록의 DOCX 내 순서와 전체 포함 여부를 자동 대조했다. 웹 결과에도 전부 포함됨을 확인했다.
- DOCX·웹 삽화 각각 3점, 실제 이미지 파일 존재, 차례 앵커와 canonical을 확인했다.
- 문서 전체 XML·머리말·꼬리말·메타데이터에서 원본 예제 및 안내 문구가 남지 않은 것을 검사했다.
- 문서 스킬의 `render_docx.py`와 번들 LibreOffice로 PDF 및 96dpi 페이지 PNG를 생성했다. 125쪽 전체를 시각 검사했다. 소제목 앞 Markdown 표시 누락 3곳을 수정하여 다시 렌더하고, 변경된 모든 페이지를 재검수했다. 변하지 않은 페이지는 PNG 동일성도 대조했다.
- 한글 표시, 삽화, 부·장 시작, 여백, 페이지 번호, 차례 쪽수, 판권과 본문 잘림을 확인했다.
- 로컬 Astro 검사 오류·경고 0건(기존 레이아웃 힌트 1건), 정적 빌드 성공. 클라이언트 테스트 7건 통과. 로컬 Worker 테스트는 샌드박스 포트 바인딩 제한으로 실행되지 않았으며 추가 권한 요청이 거절되어 재시도하지 않았다. 전체 테스트와 배포 완료 여부는 GitHub Actions 결과로 확인한다.

이번 작업은 기존 퇴고본의 매체 제작이다. 원전 대조와 저자의 경험 확인에 관한 기존 편집 기록의 남은 항목은 `EDITORIAL_REPORT.md`에 명시했다. 별도 `conversation-to-nonfiction` 스킬은 현재 환경에서 발견되지 않아 저장소 편집 매뉴얼과 문서 스킬을 적용했다.
